# Geuvara Ahmad - Personal Portfolio

## Overview
A responsive, single-page personal portfolio website built to showcase my technical skills, projects, and hobbies. The site features a clean user interface with a built-in dark/light mode toggle, interactive project cards, and a fully responsive layout that adapts to both desktop and mobile devices.

## Features
* **Theme Toggling:** A Dark/Light mode switch that remembers the user's preference using browser `localStorage`.
* **Responsive Design:** Utilizes CSS Grid and Flexbox to automatically adjust the layout for different screen sizes (mobile, tablet, desktop).
* **Interactive UI:** Smooth transitions, parallax background effects, and hidden overlay links that reveal on hover.
* **Single-Page Navigation:** Fixed header with anchor links for smooth scrolling to specific sections (Home, Skills, Projects, Hobbies, Contact).

## Technologies Used
* **HTML5:** Semantic structure and content organization.
* **CSS3:** Custom properties (variables) for theming, CSS Grid/Flexbox for layout, media queries for responsiveness, and transitions/animations.
* **Vanilla JavaScript:** DOM manipulation and local storage handling for the theme toggle.
* **Google Fonts:** "Poppins" typeface for typography.

## File Structure
* `index.html`: The core structure and content of the portfolio.
* `style.css`: All styling rules, responsive breakpoints, and dark mode color variables.
* `script.js`: The interactive logic for the theme toggle switch.
* `assets/profile.jpeg`: The background image used in the hero section.
